Configure who approves purchase / inventory / service requests (by amount for multi-level), optional edit review for sales estimates (each save after configure), and the two-step leave workflow (manager → HR). Currency thresholds: AED.

Each module has its own independent approval config. If no config is set, requests go to the default admin approver. For Estimate, enabling a row sets edit review: every save by users who are not the configured approver (and not superuser) queues a pending review and notifies the approver. For Project, choosing Completed on the edit form always sends a completion request; the configured approver must confirm on the project page (other edits save immediately). For Leave Request, use Multi Level with two fixed steps: manager first, then HR. Step 1 goes to the employee's department manager (HR → Departments); the Level 1 approver is only a fallback when no manager is assigned. Step 2 is the final HR approver. If no HR approver is set at Level 2, users with HR approve permission can finalize leave. Quot Won estimates can only be edited by a superuser; other roles must ask an administrator. Full audit trail is recorded for all approval actions. The approver list includes every active system user (same as Settings → Users).
